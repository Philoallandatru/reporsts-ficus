5.2.1. PC-compatible Expansion ROMs (Code Type 0)
This section describes the additional steps performed by the POST Firmware when handling of
ROM images that have a value of 0 in the Code Type field, indicating the image is Intel x86, PC-
compatible.
In addition, this section also describes the new field for the Expansion ROM header for Code
Type 0.

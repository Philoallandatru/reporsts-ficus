# 胶囊机制

在 [NVMe over Fabrics](/concepts/nvme-over-fabrics.md) 协议中，**胶囊（Capsule）** 是主机与 NVM 子系统之间信息交换的基本单元。^[nvme-transport-models.md:95]

## 什么是胶囊

胶囊是一个封装单元，用于在基于消息的传输模型中传递命令和响应。根据来源文档的描述，胶囊可以包含以下内容：^[nvme-transport-models.md:99-104]

- 一条 NVMe 命令或一个响应
- 可选的命令/响应数据
- 散布/聚集列表（SGL，Scatter-Gather List）

## 胶囊结构

### 命令胶囊

命令胶囊从主机发往控制器，其结构如下：^[nvme-transport-models.md:160-167]

```text
字节 0                  63 64                              N-1
┌────────────────────────┬──────────────────────────────┐
│  64 字节 SQE           │  数据 或 额外的 SGL           │
│  (提交队列条目)        │                               │
└────────────────────────┴──────────────────────────────┘
```

命令胶囊由 64 字节的提交队列条目（SQE）开头，后续可以携带数据或额外的 SGL 描述符。

### 响应胶囊

响应胶囊从子系统返回主机，其结构如下：^[nvme-transport-models.md:170-178]

```text
字节 0         15 16                                     N-1
┌──────────────────┬────────────────────────────────────┐
│  16 字节 CQE     │  可选数据                           │
│  (完成队列条目)  │                                     │
└──────────────────┴────────────────────────────────────┘
```

响应胶囊以 16 字节的完成队列条目（CQE）开头，后面可跟可选数据。

## 关键规则

在使用胶囊机制时，需要注意以下关键规则：^[nvme-transport-models.md:181-183]

1. **命令与数据不混用**：命令胶囊在 SQE 之后**不会同时混合**数据和额外的 SGL，二者只能选其一
2. **命令标识符唯一性**：SQE 中的**命令标识符**（Command Identifier）在该队列的所有未完成命令中必须唯一
3. **响应一一对应**：响应 CQE 与之前的某个命令胶囊一一对应

## 数据放置策略

通过 SGL 描述符，胶囊支持多种数据放置策略：^[nvme-transport-models.md:189-193]

| SGL 选择的数据放置方式 | 胶囊处理结果 |
|---------------------|-------------|
| **内存地址** | 数据通过传输支持的内存事务传输（如 RDMA） |
| **偏移量** | 数据直接承载在命令或响应胶囊中 |
| **额外描述符段** | 描述符紧接 SQE 之后连续排列 |

对于胶囊内数据，其布局细节如下：^[nvme-transport-models.md:197-200]

- **额外的胶囊内 SGL**：从字节 64 开始
- **胶囊内命令数据**：从字节偏移量 `64 + ICDOFF × 16` 开始
- 中间的任何字节都是未定义的

## 胶囊大小

不同类型的队列使用不同的机制确定胶囊大小：^[nvme-transport-models.md:140-145]

- **管理队列胶囊大小**：由传输绑定（Binding）固定
- **I/O 队列胶囊大小**：通过 Identify [Controller](/concepts/controller.md) 命令报告，包括 I/O 命令胶囊和 I/O 响应胶囊的大小

## 错误处理

当违反胶囊使用规则时，控制器会返回相应的错误：^[nvme-transport-models.md:204-207]

- 违反描述符数量限制：命令被中止，返回 **Invalid Number of SGL Descriptors** 错误
- SGL 偏移量无效：返回 **SGL Offset Invalid** 错误

## 相关概念

- 传输模型 — 胶囊机制应用于基于消息的传输模型
- SGL（散布/聚集列表） — 胶囊中用于描述数据放置的机制
- [NVMe over Fabrics](/concepts/nvme-over-fabrics.md) — 使用胶囊机制的网络存储协议
- 提交队列条目 (SQE) — 命令胶囊的核心组成部分
- 完成队列条目 (CQE) — 响应胶囊的核心组成部分

## 总结

胶囊机制是 [NVMe over Fabrics](/concepts/nvme-over-fabrics.md) 实现网络存储通信的基础单元，通过将命令、响应和数据封装在统一的消息结构中，实现了与传输无关的可靠数据交换。这种设计既保证了协议的灵活性，又为不同的底层网络传输（如 RDMA、TCP）提供了统一的接口。^[nvme-transport-models.md:95-104]

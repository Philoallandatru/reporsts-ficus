# 命令集选择

**命令集选择**（Command Set Selection）是 NVMe 控制器初始化过程中的关键步骤，主机根据控制器的硬件能力选择合适的命令集配置文件（Profile），从而决定控制器支持哪些 I/O 操作类型。^[nvme-controller-initialization.md:39-47]

## 核心概念

命令集选择涉及两个关键寄存器的交互：

- **CAP.CSS**（Controller Capabilities - Command Sets Supported）：控制器能力寄存器中的命令集支持字段，报告控制器原生支持的命令集类型
- **CC.CSS**（Controller Configuration - Command Set Selection）：控制器配置寄存器中的命令集选择字段，由主机设置以启用特定命令集 ^[nvme-controller-initialization.md:41]

主机必须在使能控制器（设置 `CC.EN=1`）之前完成命令集选择，因为该配置决定了控制器后续可以处理的命令类型。 ^[nvme-controller-initialization.md:51-56]

## CSS 值定义

根据 NVMe 规范，CC.CSS 字段支持以下取值： ^[nvme-controller-initialization.md:43-47]

| CSS 值 | 含义 | 说明 |
|--------|------|------|
| `111b` | 无 I/O 命令集模式（No I/O Command Set） | 仅支持管理命令（Admin Commands），不提供块存储功能 |
| `110b` | I/O 命令集组合（I/O Command Set Combination） | 支持多种命令集的组合，需进一步通过 Identify 数据结构识别具体支持的组合 |
| `000b` | NVM 命令集（NVM Command Set） | 标准块存储命令集，用于传统的 SSD 和 NVMe 设备，需满足 CAP.CSS 中定义的能力条件 |

## 选择流程

命令集选择是初始化序列中的一部分，通常遵循以下步骤： ^[nvme-controller-initialization.md:59-73]

1. **读取控制器能力**：主机读取 CAP 寄存器，获取 `CAP.CSS` 字段支持的命令集类型
2. **设置命令集配置**：根据业务需求和控制器能力，设置 `CC.CSS` 为合适的值
3. **使能控制器**：设置 `CC.EN=1` 后，等待 `CSTS.RDY=1`
4. **命令集特定识别**：控制器就绪后，对于 `CC.CSS=110b`（命令集组合）的情况，主机需要通过 Identify 命令识别可用的命令集组合并选择配置文件
5. **枚举命名空间**：为每个已使能的 I/O 命令集执行相应的识别和配置操作

## 命令集组合模式

当控制器支持 `CC.CSS=110b` 时，意味着控制器能够同时支持多种 I/O 命令集。这种情况下： ^[nvme-controller-initialization.md:65-66]

- 主机需要通过 Identify [[controller|Controller]] 数据结构识别控制器支持的所有命令集组合
- 从可用组合中选择与主机需求匹配的配置
- 对每个已使能的 I/O 命令集执行命令集特定的识别操作

## 与初始化阶段的关系

命令集选择位于 NVMe 控制器初始化的配置阶段，与以下步骤紧密关联： ^[nvme-controller-initialization.md:49-55]

- **仲裁机制选择**：与命令集选择并行，主机还需从控制器支持的仲裁方式中选择一种
- **内存页大小配置**：选择与系统内存管理匹配的内存页大小
- **就绪等待**：完成配置后，设置 `CC.EN=1` 并轮询等待 `CSTS.RDY=1`

# 管理队列配置

管理队列（Admin Queue，简称 AQ）是 NVMe 控制器中用于承载管理命令的专用队列，是主机与控制器之间建立通信的初始通道。所有管理操作——包括控制器识别、命名空间枚举、I/O 队列创建以及功能配置——均通过管理队列完成。

^[nvme-controller-initialization.md:3-5]

## 配置参数

管理队列由三组关键寄存器/参数定义其属性：

| 参数 | 全称 | 说明 |
|------|------|------|
| **AQA** | Admin Queue Attributes | 定义管理队列的属性，包括队列深度等 |
| **ASQ** | Admin Submission Queue Base Address | 管理提交队列的物理内存地址 |
| **ACQ** | Admin Completion Queue Base Address | 管理完成队列的物理内存地址 |

^[nvme-controller-initialization.md:25, 82]

## 基于内存传输（PCIe）的配置

对于 PCIe 控制器，管理队列在控制器处于**禁用状态**且 `RDY=0` 时进行配置。配置流程如下：

1. 读取控制器能力寄存器，了解支持的配置选项
2. 配置 `AQA`、`ASQ`、`ACQ` 寄存器，设置管理队列的基地址和队列深度
3. 选择命令集（`CC.CSS`）、仲裁机制（`CC.AMS`）和内存页大小（`CC.MPS`）
4. 设置 `CC.EN=1` 使能控制器
5. 轮询等待 `CSTS.RDY=1`，确认控制器就绪

^[nvme-controller-initialization.md:16, 55]

## 基于消息传输（Fabrics）的配置

对于 NVMe-oF Fabrics 传输，管理员队列的配置方式与 PCIe 有显著不同：

1. 首先建立传输层连接（Transport Layer Connection）
2. 执行 **Connect 命令**，该命令自动创建 Admin 队列对（Admin Queue Pair）并建立关联（Association）
3. 若 `AUTHREQ != 0`，需要在正常初始化之前完成身份认证
4. 使用 Fabrics **Property Get/Set** 命令访问控制器能力（CAP）和配置（CC）寄存器
5. 设置 `CC.EN=1` 并等待 `RDY=1`

^[nvme-controller-initialization.md:25-27, nvme-controller-initialization.md:82-84]

> **补充说明**：成功的 Connect 命令会在任何必需的带内身份认证（in-band authentication）交换之前创建 Admin 或 I/O 队列。如果主机在建立关联后 2 分钟内未设置 `CC.EN=1`，控制器可能会移除该关联。 ^[nvme-controller-initialization.md:87]

## 配置命令集选择

主机需要根据控制器能力寄存器 `CAP.CSS`（Controller Capabilities - Command Sets Supported）来决定命令集配置 `CC.CSS`（Controller Configuration - Command Set Selection）：

| CSS 值 | 含义 | 说明 |
|--------|------|------|
| `111b` | 无 I/O 命令集模式 | 仅支持管理命令 |
| `110b` | I/O 命令集组合 | 支持多种命令集的组合 |
| `000b` | NVM 命令集 | 标准块存储命令集 |

^[nvme-controller-initialization.md:41-48]

## 初始化顺序

管理队列必须在 I/O 队列创建之前完成配置。控制器就绪后的标准操作顺序为：

1. **识别控制器**：执行 `Identify Controller` 命令
2. **发现命令集**：识别控制器支持的 I/O 命令集组合
3. **枚举命名空间**：遍历活动的命名空间标识符
4. **读取标识结构**：获取命令集特定的 Identify 数据结构
5. **配置 I/O 队列**：创建完成队列（CQ）后创建提交队列（SQ）
6. **配置异步事件**：在任意时刻配置异步事件通知

^[nvme-controller-initialization.md:61-72]

## 与相关概念的关系

管理队列配置是 [[控制器初始化]] 过程中的核心环节，依赖于 传输类型 的差异（PCIe vs Fabrics）。管理队列创建完成后，才能进行 [[命名空间]] 枚举、 I/O 队列 创建以及 异步事件 配置等后续操作。 ^[nvme-controller-initialization.md:3-11]

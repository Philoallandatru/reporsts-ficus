# 专利检索入口工具链

本文档整理 SSD 控制器固件 / 硬件研究场景下的专利检索入口工具链，包括检索工具、CPC 分类体系、种子专利和可复用查询模板。

## 检索工具入口

| 工具 | 推荐用途 | 入口地址 | 注意事项 |
|---|---|---|---|
| Google Patents | 快速发现、 assignee 过滤、CPC 过滤、引用链追踪、机器翻译 | https://www.google.com/advanced_patent_search | 非法定记录系统；涉及法律状态时需通过 USPTO Patent Center 或对应专利局核验 |
| USPTO Patent Public Search | 美国专利及公开申请的权威检索入口 | https://www.uspto.gov/patents/search/patent-public-search | 以美国为主；CN/EP/WO 同族专利需通过 Google Patents 家族链接或各国专利局检索 |
| USPTO Patent Center | 按申请号、专利号、PCT 号或公开号查询申请状态及文档 | https://patentcenter.uspto.gov | 不适合宽泛关键词发现；用于确认而非首轮挖掘 |

## CPC 分类体系

CPC（Cooperative Patent Classification）由 USPTO 和 EPO 联合维护，是 SSD 控制器领域专利分类的主要词汇来源。

| 分类节点 | 覆盖范围 | 入口地址 |
|---|---|---|
| G06F 3/06 | 数字输入/输出至记录载体的接口，包含 RAID、模拟记录载体和网络化记录载体 | https://www.uspto.gov/web/patents/classification/cpc/html/cpc-G06F.html |
| G06F 12/00 | 内存系统或架构内部的访问、寻址或分配 | https://www.uspto.gov/web/patents/classification/cpc/html/cpc-G06F.html |
| G06F 11/00 | 计算系统错误检测、纠错和监控 | https://www.uspto.gov/web/patents/classification/cpc/html/cpc-G06F.html |
| G11C 16/00 | 可擦除可编程只读存储器，尤其是 NAND 编程/读取/擦除、干扰、感测、阈值、保固和磨损机制 | https://www.uspto.gov/web/patents/classification/cpc/html/cpc-G11C.html |
| H10B | 个别电子存储器件结构，尤其 3D NAND 核心/外围/阶梯结构 | https://www.uspto.gov/web/patents/classification/cpc/html/defH10B.html |
| H03M 13 | LDPC、BCH、Reed-Solomon、迭代解码、软解码、速率兼容 LDPC 及实现复杂度 | https://www.uspto.gov/web/patents/classification/cpc/html/cpc-H03M.html |

> **注意**：CPC 符号频繁修订，采集时应记录 CPC 版本和日期，并关注后续重新分类说明。

| 掉电保护（PLP） | 明确描述 SSD 掉电保护、备用电源、超级电容和易失性缓冲区刷新行为 | https://patents.google.com/patent/US20170185335A1/en |

| 数据放置 / FDP | 明确引用灵活数据放置、回收单元、句柄和设备级垃圾回收影响 | https://patents.google.com/patent/US12405729B2/en |

## 可复用查询模板

以下模板可直接粘贴至 Google Patents 使用，适合作为每次检索的起点。

| 主题 | 查询模板 | 覆盖范围 |
|---|---|---|
| FTL / 垃圾回收 / 磨损均衡 | `flash translation layer SSD "garbage collection" "wear leveling"` | FTL 映射、GC、压缩和磨损均衡专利 |
| PLP / 掉电保护 | `"solid state drive" "power loss protection" capacitor flush` | 结合硬件能量储备和固件刷新/关机行为的 PLP 实现 |
| LDPC / 软解码 | `NAND LDPC "soft decoding" "read retry"` | NAND 可靠性、ECC 和控制器读恢复管道的交叉检索 |
| SLC Cache / pSLC | `"SLC cache" SSD TLC QLC "pseudo-SLC"` | 以 SLC 模式编程多比特单元换取写入性能的控制器策略 |
| 放置 / FDP / Streams | `"flexible data placement" SSD "reclaim unit" "placement identifier"` | 现代主机定向放置及与内部 GC 和写放大交互的 FDP 类接口 |
| NAND 器件 / 干扰 / 保固 | `"NAND flash" "threshold voltage" disturb retention "read retry"` | 控制器固件必须补偿的低层器件行为 |

## 采集标签建议

| 标签 | 用途 |
|---|---|
| `patent/cpc/g06f-3-06` | SSD 控制器、主机接口、存储虚拟化、FTL、GC、放置和 RAID 类存储专利 |
| `patent/cpc/g11c-16` | NAND 编程/读取/擦除、感测、干扰、保固和存储单元行为 |
| `patent/cpc/h03m-13` | LDPC/BCH/RS 编码、迭代解码、软解码和 ECC 硬件实现 |
| `patent/topic/plp` | 掉电保护、突发断电恢复、电容支撑刷新和元数据保留 |
| `patent/topic/slc-cache` | SLC 缓存、伪 SLC、混合缓存、折叠和动态单级/多级配置 |
| `patent/topic/fdp-placement` | FDP、Streams、主机提示、放置标识符、回收单元、冷热数据分离和 WAF 降低 |

## 与其他页面的关系

- 专利检索的结果（受让人、模块名、生命周期语义）可进入 控制器厂商数据采集与建模。
- 从专利中提取的硬件模块名和接口术语可对照 控制器硬件模块边界 和 控制器 RTL / IP 参考 验证合理性。
- 与 FTL 相关的专利术语（如 GC、wear leveling）应与 FTL 元数据格式与恢复约定 交叉对齐。
